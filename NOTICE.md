`runtime/open62541.c` and `runtime/open62541.h` are the open62541
amalgamation (https://www.open62541.org, https://github.com/open62541/open62541,
tag `v1.4.22`, commit `a9d7e2f`), © the open62541 authors, distributed
under the Mozilla Public License 2.0 (https://mozilla.org/MPL/2.0/). Their
source form is the upstream repository at that tag ; the MPL-2.0 applies
to these two files, the rest of the package is Apache-2.0.

They are generated by `tools/gen-amalgamation.ps1` with the upstream CMake
tooling and these options, instead of the release files :

| Option | Value | Why |
|---|---|---|
| `UA_ENABLE_ENCRYPTION` | `OPENSSL` (release : `MBEDTLS`) | One TLS stack in Amalgame : OpenSSL, as amalgame-pollen and amalgame-tls |
| `UA_ENABLE_PUBSUB` | `OFF` (release : `ON`) | Client / server only ; PubSub encryption is mbedTLS-only in 1.4 |
| `UA_AMALGAMATION_MULTIARCH` | `ON` | POSIX or Win32 chosen at compile time, like the release |

One source change, in `open62541.c` : `ua_client_connect.c` and
`ua_pki_openssl.c` both define a `static openssl_PEM_PRE`, which clashes
once both are in one file with OpenSSL encryption. The client one is
renamed `openssl_PEM_END_client` (2 lines, marked `amalgame-opcua` in the
file). The code is gone from the open62541 1.5 branch.

SHA-256 of the files as committed : see `git log -- runtime/open62541.c`.
