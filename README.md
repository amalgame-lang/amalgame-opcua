# amalgame-opcua

> OPC UA for [Amalgame](https://github.com/amalgame-lang/Amalgame) : a client that reads many nodes in one request and **browses a server's address space with engineering units and ranges**, and a small server for tests and demos. Over [open62541](https://www.open62541.org) v1.4.22 (vendored, MPL-2.0).

Linux in v0.1 (tested on Ubuntu 24.04). Windows needs `ws2_32` / `iphlpapi`, and the package manifest has no per-OS libraries yet.

## Status

**v0.1.0** : client (connect, `ReadMany`, `BrowseTree`, status codes), test server (folders, analog items with `EURange` and `EngineeringUnits`, Int16 variables, writes). Security mode None (anonymous) : the library is built with OpenSSL encryption, and certificates come in v0.2.

## Client

```amalgame
import Amalgame.OpcUa

let h: int = OpcUa.Connect("opc.tcp://192.168.1.20:4840", 2000)   // url, timeout in ms
let n: int = OpcUa.ReadMany(h, "ns=2;s=P1.Debit,ns=2;s=P1.Etat")   // one Read request
if (n < 0) { Console.WriteLine("read failed : " + OpcUa.LastError(h)) }
let debit: float = OpcUa.Value(h, 0)
if (OpcUa.Status(h, 1) != 0) { Console.WriteLine(OpcUa.StatusName(OpcUa.Status(h, 1))) }   // e.g. BadNodeIdUnknown
OpcUa.Close(h)
```

`BrowseTree(h, root, maxDepth, maxNodes)` walks the address space from `root` (`"i=85"` : Objects), breadth-first, and returns every **variable** as JSON :

```json
[{"node":"ns=1;s=Station.Pompage.P1.Debit","path":"Station.Pompage.P1.Debit","name":"Debit",
  "type":"Double","value":212.5,"unit":"m³/h","range":[0,400]}]
```

`unit` and `range` come from the `EngineeringUnits` and `EURange` properties (OPC UA analog items, DA). With them, an application can bind a server's variables to its model without a tag list. Kairos's Designer does. The server's own diagnostics (namespace 0) are left out.

| Return | Meaning |
|---|---|
| `Connect` ≥ 0 | a handle ; a server that does not answer yet still gets one, and every call connects again (`IsConnected`, `LastError`) |
| `Connect` = -1 | not an `opc.tcp://` URL, or 32 handles open |
| `ReadMany` ≥ 0 | how many values are good ; per value : `Value(h, i)`, `Status(h, i)` (0 = good) |
| `ReadMany` = -1 | the server cannot be reached ; -4 : bad handle |

Numbers of every built-in type are returned as `float` (booleans 0 / 1).

## Server (tests, demos)

```amalgame
OpcUa.ServerStart(4840)                                                     // one per process
OpcUa.ServerAddAnalog("Station.Pompage.P1", "Debit", 212.5, 0.0, 400.0, "m³/h")   // ns=1;s=Station.Pompage.P1.Debit
OpcUa.ServerAddInt("Station.Pompage.P1", "Etat", 6)
OpcUa.ServerSet("ns=1;s=Station.Pompage.P1.Debit", 301.25)
```

Folders of the dotted path are created under Objects ; node ids are `ns=1;s=<path>.<name>`.

## Tests

```bash
./tests/run_am_tests.sh [amc]     # stages the working tree as v0.0.0-dev and runs tests/*.am
```

`tests/opcua_smoke.am` : 16 checks (browse with unit, range, type and value ; three nodes in one read, one unknown ; a value written on the server read back ; no server ; bad URL). The package takes about 2 minutes to compile the first time (14 MB of C).

## open62541

`runtime/open62541.c` / `.h` are generated by `tools/gen-amalgamation.ps1` with OpenSSL encryption and without PubSub. See `NOTICE.md` for the options, the one source change, and the MPL-2.0.
